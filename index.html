01 / QUEM ESTÁ POR TRÁS DO CÓDIGO

Curiosidade é o começo.
Consistência faz acontecer.

Gosto de entender o que existe por trás de uma tela: como os dados viajam, como as regras funcionam e como cada parte se conecta para entregar uma experiência que faça sentido.

Minha jornada passa por exercícios de lógica, aplicações desktop, páginas web, APIs e a construção de um sistema full-stack como projeto acadêmico. Cada projeto é uma oportunidade de sair da teoria, encontrar problemas reais e melhorar a forma como escrevo e organizo código.

“Código bom não é só código que funciona. É código que pode ser entendido, mantido e evoluído.”— Meu jeito de pensar desenvolvimento
